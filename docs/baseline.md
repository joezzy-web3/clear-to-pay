Generated by `scripts/baseline.sh` from `src/baseline_tests.rs` (the test fails if any row changes).
Two baselines, both with the contract's per-payment and per-period limits: a global allowlist (the agent
may pay any supplier's approved address, as many agent spending firewalls do), and a stronger per-supplier
allowlist (each supplier only at its own approved address).
