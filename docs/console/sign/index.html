      How your signing key works

      1. This phone made you a signing key. The private part never leaves this phone. Nobody, including the buyer, will ever ask you for it.
      2. Tap Send to buyer, once. It sends only the public part, so the buyer can add you as the storekeeper (or weighbridge).
      3. When goods arrive, the buyer sends you a delivery link. Open it on this phone, check the note against what you received, and tap Sign delivery. Then tap Send back.
      4. New phone or cleared browser? Make a new key here and send it again; the buyer removes the old one.
      Make your key below first.

      Your signing key pair

      A key pair is two halves. The public key is shown below and is safe to share: the buyer registers it. The private key stays on this phone. It is never shown and never sent, and nobody, including the buyer, will ever ask you for it.

      Demo-grade key storage: the key is kept in this browser's storage for this site only. Anyone with this phone unlocked could use it. For real deliveries, use a hardware-backed key.
